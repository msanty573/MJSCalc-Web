# MJSCalc — browser demo

Four pages of [MJSCalc](https://mjsapps.net/mjscalc/) running in the browser with [Pyodide](https://pyodide.org). The calculations in `py/` are the desktop app's own engine. Built by MJSCalc's `packaging/build_web.py` — don't edit here.
